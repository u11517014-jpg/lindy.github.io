課程總覽與版本控管

本課程核心在於建立標準的現代 Web 開發流程。透過 GitHub 工作流進行專案佈署，並掌握網頁 HTML 語意化設計與 CSS 樣式排版基礎。

GitHub Pages 部署
練習正確上傳解壓檔案至根目錄，避免無效資料夾包裝與 ZIP 檔案誤傳。
相對路徑觀念
嚴格使用相對路徑引用資源（如圖片、影音），確保網頁跨平台順利渲染。

HTML5 語意化獨立實作 (活動 01-04)

活動名稱 重點技術與標籤 成果檔案與說明
活動 01：文字層級 h1~h3, p, b, i, sub, sup 「水與生活：小小科學探索日」網頁
活動 02：多媒體運用 img (alt/width), audio, video 校園自然觀察任務卡 (整合 PNG/SVG 及音效/影片)
活動 03：清單與表格 ul, ol, table, tr, th, td 紙橋挑戰社：活動準備頁 (包含材料、步驟與分工表)
活動 04：互動表單 label, input, select, radio, checkbox 放學後社團體驗表 (包含完整的輸入元件與驗證)

CSS 視覺樣式與無障礙設計 (活動 05-09)

活動 05：視覺風格與盒模型
掌握 Padding, Margin, HEX 顏色碼與 05-color-lab 色彩實驗室運用。
活動 06：CSS Grid 網格佈局
比較單欄、雙欄、三欄與側欄主內容版型，靈活使用 fr 與 minmax()。
活動 07：Flexbox 卡片排列
彈性排列卡片，搭配 object-fit: cover 確保圖片等高且不變形。
活動 08：RWD 響應式佈局
設定 max-width 搭配 Media Query @media (max-width: 600px) 適應行動裝置。
活動 09：Web 無障礙設計 (Accessibility)
使用 WAVE 工具進行機檢，修復 Low Contrast 文字對比度與缺失 Form Label 的問題，並補全 :focus-visible 鍵盤無障礙焦點。
